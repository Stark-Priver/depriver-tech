The finale of **Njia za Tech**: five yes/no questions, nine possible paths. Answer honestly, not with what sounds cool. *Njia yako ni ipi?*

## The quiz

**1. Do you care more about how things look and feel than how they work inside?**
Yes → question 2. No → question 3.

**2. Would you rather sketch and test ideas with users than write code all day?**
Yes → **UI/UX Designer** (#05). No → **Frontend** (#02) if you love the browser, **Mobile** (#06) if you love apps.

**3. Do you enjoy finding stories and answers hidden in numbers?**
Yes → **Data Analyst** (#03). No → question 4.

**4. Do you like thinking like an attacker so you can protect systems?**
Yes → **Cybersecurity** (#04). No → question 5.

**5. Do you prefer keeping systems running and automating them over building features?**
Yes → **DevOps Engineer** (#07). No → **Backend Developer** (#01).

Love helping people more than code? Look at **IT Support** (#08) or **Product Manager** (#09).

Open source projects share their code publicly, and anyone can suggest improvements. Your first contribution can be small. *Changia dunia.*

## Why

You learn from real codebases, get reviewed by experienced developers for free, and build a portfolio that proves teamwork. Many senior developers started with a tiny typo fix.

## Ways to help without being senior

Docs (fix unclear README steps) · **Kiswahili translations** · clear bug reports · a missing test · design (icons, screenshots, UX notes) · small fixes labelled “good first issue”. Many apps need Kiswahili, and that's a contribution we can make better than most.

## Find a project

Start with a library you already use, search GitHub issues for the **good first issue** label, look for Swahili (`sw`) on translation platforms like Weblate or Crowdin, and check the project is alive (recent commits, maintainers replying). Read `CONTRIBUTING.md` first.

## From fork to pull request

1. **Fork:** your own copy on GitHub.
2. **Clone and branch:** `git checkout -b fix-readme`.
3. **Make one small change** and test it locally.
4. **Commit and push** with a clear message.
5. **Open a pull request** explaining what and why.

## A good pull request

> **Fix install steps for Windows in README** (#512)
> The guide says `make install`, which doesn't work on Windows. I added the PowerShell command and tested it on Windows 11. Fixes #498.

Clear title, why and how you tested it, and a link to the issue. Small, focused PRs get merged faster.

## Etiquette

Ask before big changes, accept feedback calmly, be patient (maintainers are often volunteers), and never send spam PRs that change one word just to get a contribution. Your GitHub history is public forever.

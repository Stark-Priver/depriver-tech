They build everything you see and touch in a website or web app: the screens, the buttons and how it feels. This is part of **Njia za Tech**, a series that explains one tech career at a time, honestly. *Unachokiona ni kazi yao.*

## What they actually do

A designer draws the screen. The frontend developer turns it into real code that loads fast, works on a cheap phone and talks to the backend.

- Turn designs into working pages
- Make it work on every screen size
- Connect the screens to the API

**Like this:** A shop: the frontend is the shelves, the lights and the counter. If customers can't find things, they leave.

## A normal working day

| Time | Task |
|---|---|
| 08:30 | Stand-up with the team |
| 09:00 | Build the new checkout screen from the design |
| 12:00 | Test it on a small Android phone and fix the layout |
| 14:30 | Connect the form to the backend API |
| 16:30 | Pull request, review, fix comments |

Every day is different, but this is the rhythm.

## The tools

- **The base · learn first:** HTML, CSS, JavaScript
- **Frameworks:** React, Vue, Tailwind CSS, Next.js
- **Every day:** Browser DevTools, Git, Figma (reading designs), APIs / JSON

Nobody learns all of these at once. Start with the first one.

## Is this path for you?

You'll enjoy it if you like: seeing your work on the screen right away; details: spacing, colours, smooth clicks; thinking about how real people use things.

Maybe not if: you never want to touch design; small visual details annoy you.

You can try a path for a month before you decide.

## How to start, for free

1. **HTML and CSS first.** Build three static pages from scratch.
2. **Then JavaScript.** Make buttons, forms and lists react.
3. **Copy a real site's layout.** A bank or school homepage, for practice only.
4. **Learn one framework.** React or Vue, then deploy free.

**First project idea:** A restaurant menu site that works perfectly on a TZS 150k phone.

## Who hires frontend developers in Tanzania

Software houses and agencies, Banks and fintech, Startups, Media and e-commerce, Freelance websites and remote teams.

**What about pay?** Pay depends on skill, company and city. Ask people who do the job. We don't publish salary numbers we can't check.

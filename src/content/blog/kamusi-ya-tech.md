Darasani tunasikia maneno haya kila siku, lakini mara nyingi hakuna anayeyaeleza kwa lugha rahisi. Hii ni **Kamusi ya Tech**: maneno ya tech kwa Kiswahili rahisi, kila moja na mfano wa maisha ya kila siku. Toleo la kwanza lina maneno manane.

## API *(nomino)*: Application Programming Interface
**Maana:** Njia ambayo programu moja huongea na programu nyingine na kubadilishana taarifa.
**Mfano:** Mhudumu wa mgahawa. Unaagiza chakula (request), jikoni wanapika, mhudumu anakuletea (response). Huoni jikoni, unapata chakula tu.
*"App yetu inachukua hali ya hewa ya Mbeya kupitia API."*

## Bug *(nomino)*
**Maana:** Hitilafu kwenye code inayofanya programu ifanye kitu ambacho hukutarajia.
**Mfano:** Calculator inasema 2 + 2 = 22. Kutafuta na kurekebisha bug ndiyo *debugging*.

## Git *(nomino)*
**Maana:** Mfumo unaohifadhi historia ya kila mabadiliko kwenye code yako, hatua kwa hatua.
**Mfano:** Kama save points kwenye game. Hakuna tena `final_FINAL2.zip`. GitHub ni mahali project za Git zinakaa mtandaoni.

## Deploy *(kitenzi)*
**Maana:** Kuhamisha programu yako kutoka kwenye kompyuta yako na kuiweka mtandaoni ili watu waitumie.
**Mfano:** Kupika nyumbani dhidi ya kufungua mgahawa. "Inafanya kazi kwenye laptop yangu" haitoshi mpaka u-deploy.

## Server *(nomino)*
**Maana:** Kompyuta inayohudumia tovuti au programu kwa watumiaji wengi, masaa 24.
**Mfano:** Kama duka lisilofungwa kamwe: wateja (browsers) wanakuja wakati wowote, na duka linawahudumia.

## Cloud *(nomino)*: wingu
**Maana:** Kutumia server na huduma za kampuni nyingine kupitia internet badala ya kununua zako.
**Mfano:** Kupanga nyumba badala ya kujenga. Google Drive ni cloud: picha zako ziko kwenye server za mtu mwingine.

## Database *(nomino)*: hifadhidata
**Maana:** Mahali data huhifadhiwa kwa mpangilio ili itafutwe, ibadilishwe na ipatikane haraka.
**Mfano:** Daftari la mauzo la duka, ila unaweza kutafuta mauzo ya mwaka mzima kwa sekunde moja.

## Framework *(nomino)*: kiunzi
**Maana:** Msingi uliotengenezwa tayari, wenye sheria na zana, unaojengea programu haraka.
**Mfano:** Kiunzi cha nyumba kilichosimamishwa tayari: wewe unajenga kuta na kupamba, hauanzi kuchimba msingi. Mifano: Laravel, React, Django.

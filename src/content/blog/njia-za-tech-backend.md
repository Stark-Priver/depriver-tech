They build the part of an app you never see: the logic, the data and the security behind every button. This is part of **Njia za Tech**, a series that explains one tech career at a time, honestly. *Jikoni ndiko kazi ilipo.*

## What they actually do

When you tap “Lipa” in an app, the backend checks who you are, saves the order, talks to the payment provider and sends the answer back.

- Build APIs the app talks to
- Design and protect the database
- Keep the system fast and safe

**Like this:** A restaurant: the frontend is the dining room and the menu. The backend is the kitchen, the store and the cashier's book.

## A normal working day

| Time | Task |
|---|---|
| 08:30 | Stand-up: 15 minutes with the team on today's tasks |
| 09:00 | Build a new API endpoint for a feature |
| 11:30 | Review a teammate's pull request |
| 14:00 | Fix a bug a user reported from the logs |
| 16:00 | Write tests, then deploy to staging |

Every day is different, but this is the rhythm.

## The tools

- **Languages · pick one:** Python, PHP, JavaScript (Node), Java, Go
- **Frameworks:** Django, Laravel, Express, Spring
- **Every day:** SQL & PostgreSQL, Git, APIs / JSON, Linux terminal

Nobody learns all of these at once. Start with the first one.

## Is this path for you?

You'll enjoy it if you like: solving puzzles and making logic work; data, rules and how things connect; building things that must never break.

Maybe not if: you only enjoy visual design; you hate reading error messages.

You can try a path for a month before you decide.

## How to start, for free

1. **Learn one language well.** Python or PHP, the basics until loops feel easy.
2. **Learn SQL.** Tables, SELECT, JOIN. Every backend uses data.
3. **Build a small API.** A to-do or a shop: create, read, update, delete.
4. **Add login and deploy it.** Then put the link on your CV and GitHub.

**First project idea:** A shop stock API: products, sales and a daily total.

## Who hires backend developers in Tanzania

Banks and mobile money, Telecom companies, Startups and software houses, Government systems, NGOs and health projects and freelance and remote.

**What about pay?** Pay depends on skill, company and city. Ask people who do the job. We don't publish salary numbers we can't check.

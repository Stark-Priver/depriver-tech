Toleo 02 la **Kamusi ya Tech**: the words of your first programming class, explained in plain Kiswahili with examples from daily life.

## Algorithm */al-go-ri-dhim/* (nomino)

**Mpangilio wa hatua.** Hatua kwa hatua, kwa mpangilio, za kutatua tatizo fulani.

*In English:* A step-by-step set of instructions to solve a problem.

**Mfano:** Mapishi ya chai: chemsha maji, weka majani, ongeza maziwa, weka sukari. Ukibadilisha mpangilio, chai inaharibika.

> “Kabla ya ku-code, andika algorithm kwenye karatasi.”

## Variable */ve-ri-a-bo/* (nomino)

**Kibadilika.** Jina linalohifadhi thamani fulani ndani ya programu, na thamani hiyo inaweza kubadilika.

*In English:* A named box in a program that stores a value you can change.

**Mfano:** Sanduku lenye lebo “bei”. Leo lina 5000, kesho unaweza kuweka 6000. Lebo ni ile ile.

> “Weka jina la mteja kwenye variable inayoitwa jina.”

## Function */fank-shen/* (nomino)

**Kazi / kitendakazi.** Kipande cha code chenye jina, kinachofanya kazi moja, na unaweza kukiita mara nyingi.

*In English:* A named block of code that does one job and can be reused.

**Mfano:** Mashine ya juisi: unaweka matunda (input), unabonyeza, unapata juisi (output). Hutengenezi mashine mpya kila siku.

> “Tengeneza function moja ya kukokotoa VAT.”

## Loop */luup/* (nomino)

**Mzunguko.** Njia ya kurudia kazi ile ile mara nyingi bila kuandika code upya.

*In English:* Code that repeats an action many times.

**Mfano:** Mwalimu anaita majina ya wanafunzi 60 mmoja mmoja. Loop inafanya hivyo kwa kila jina kwenye orodha.

> “Tumia loop kutuma SMS kwa wateja wote.”

## Frontend */front-end/* (nomino)

**Sehemu ya mbele.** Sehemu ya programu au tovuti ambayo mtumiaji anaiona na kuigusa.

*In English:* The part of an app users see and interact with.

**Mfano:** Ukumbi wa mgahawa: meza, menyu, mapambo. Mteja anaona hiki tu.

> “Frontend yetu imejengwa kwa React.”

## Backend */bak-end/* (nomino)

**Sehemu ya nyuma.** Sehemu isiyoonekana inayoshughulikia mantiki, data na usalama wa programu.

*In English:* The hidden part of an app: logic, data and security.

**Mfano:** Jikoni kwa mgahawa: chakula kinapikwa, stoo, hesabu. Mteja haoni, lakini bila jikoni hakuna chakula.

> “Backend inahifadhi oda zote kwenye database.”

## Open source */o-pen sos/* (nomino)

**Chanzo huria.** Programu ambayo code yake iko wazi: mtu yeyote anaweza kuisoma, kuitumia na kuchangia.

*In English:* Software whose code is public for anyone to read, use and improve.

**Mfano:** Mapishi ya bibi yaliyoandikwa kwenye ubao wa kijiji: kila mtu anaweza kupika, na kuongeza ujuzi wake.

> “Linux na Python ni open source.”

## Debugging */di-ba-ging/* (kitenzi)

**Kutafuta na kurekebisha makosa.** Kazi ya kutafuta chanzo cha kosa kwenye code na kulirekebisha.

*In English:* Finding the cause of a bug and fixing it.

**Mfano:** Fundi wa gari anasikiliza mlio, anafungua, anajaribu sehemu moja moja mpaka apate tatizo.

> “Nimetumia saa mbili ku-debug, kumbe nilisahau koma.”

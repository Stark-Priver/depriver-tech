I learnt to code on paper. Literally: Java written by hand in an exam room, where one missing semicolon could cost you marks. Then I got a job as a software engineer while I was still a student, and found out how different the real world is. Shule si bure, though. Paper code trained my logic. It just wasn't the whole story.

## Six rounds: Darasani vs Kazini

1. **Code on paper vs code on screen (Mantiki kwanza, sintaksia baadaye).** At school you write code on paper and get marked on syntax. At work you have an editor, a linter and autocomplete, and you run the code fifty times a day. The real skill is logic and reading error messages. *Do this:* type your paper code on a computer the same day.
2. **Memorise it vs find it (Hakuna anayekariri kila kitu).** Exams reward cramming definitions word for word. At work nobody memorises everything; seniors search, read docs and ask questions all day. *Do this:* practise reading official documentation, not only lecture notes.
3. **Group work vs teamwork (Kazi ya kikundi, si ya mtu mmoja).** We all know the group assignment where one person does everything and the rest just add their names, then it travels around on a flash drive as `final_FINAL2.zip`. At work everyone ships, and Git plus code review show exactly who did what. *Do this:* do your part, and put it on GitHub from day one.
4. **Toy projects vs real users (Mteja hasomi code yako).** A calculator, a student management system, and your lecturer is the only user. Real users bring real money, slow networks and every edge case you forgot. *Do this:* build one thing a real person uses, every semester.
5. **Diagrams vs production (Kwangu inafanya kazi, haitoshi).** At school you draw the OSI model and the waterfall SDLC for marks. At work there are servers, domains, deploys, and something breaking at 3 a.m. "It works on my machine" is not done. *Do this:* deploy your project online, even on a free tier.
6. **Grades vs GitHub (Vitendo vinaongea zaidi).** At school GPA and certificates are the scoreboard. At work the question is "show me what you've built". That's how I got hired while I was still a student. *Do this:* keep three projects you can demo in two minutes.

## Still in school? Start now

- Type up your paper code the same day
- Ship a real project every semester
- Live on GitHub: commit, push, repeat
- Use AI as a tutor, not a copy machine
- Treat field practical like a real job
- Respect the fundamentals: data structures, logic, maths

Learn it in class. Prove it in projects. **Shule inakupa msingi, nyumba unajenga wewe.**

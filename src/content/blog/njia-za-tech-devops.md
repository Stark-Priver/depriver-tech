They keep systems online and help teams release new code safely, quickly and often. This is part of **Njia za Tech**, a series that explains one tech career at a time, honestly. *Mfumo usilale hata usiku.*

## What they actually do

They set up servers and cloud, automate testing and deployment, and get alerted first when the system goes down at 2 a.m.

- Automate builds, tests and deploys
- Manage servers and cloud
- Monitor uptime and fix outages

**Like this:** The engineer of a bus company: keeps the buses serviced, the routes running, and fixes breakdowns fast.

## A normal working day

| Time | Task |
|---|---|
| 08:30 | Check the overnight uptime and alerts |
| 09:30 | Fix a failing deploy pipeline |
| 11:30 | Move an app into Docker |
| 14:00 | Set up backups and test a restore |
| 16:00 | Write the runbook for the on-call team |

Every day is different, but this is the rhythm.

## The tools

- **Foundations:** Linux, Networking, Bash scripting
- **Tools:** Docker, GitHub Actions, Nginx, Kubernetes
- **Cloud:** AWS, Google Cloud, Azure, Monitoring

Nobody learns all of these at once. Start with the first one.

## Is this path for you?

You'll enjoy it if you like: automating boring, repeated work; understanding how all the parts connect; solving problems under pressure.

Maybe not if: you hate the terminal; you never want to be woken by an alert.

You can try a path for a month before you decide.

## How to start, for free

1. **Learn Linux properly.** Files, permissions, services, SSH.
2. **Deploy an app by hand.** A cheap VPS, Nginx, a domain.
3. **Then containerise it.** Put the same app in Docker.
4. **Automate with CI/CD.** GitHub Actions: test and deploy on push.

**First project idea:** Deploy your portfolio with Docker and auto-deploy it on every git push.

## Who hires DevOps engineers in Tanzania

Banks and fintech, Telecoms, Software houses, Hosting and data centres, Startups and remote teams.

**What about pay?** Pay depends on skill, certificates and company. Ask people who do the job. We don't publish salary numbers we can't check.

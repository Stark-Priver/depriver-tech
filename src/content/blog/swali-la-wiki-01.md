**Swali la Wiki** (question of the week) is a new series. Every week I answer one question from students, from comments, DMs and talks. This first one is a question I get a lot:

> **"Naweza kujifunza coding kwa simu tu?"** Can I learn to code with only a phone?

## Jibu fupi: Ndiyo, lakini...

Yes, you can start on a phone. But plan to move to a computer for real projects. Don't wait for a laptop to start learning. *Simu inatosha kuanza.*

## Your phone is a classroom

1. **Learn the basics in the browser.** freeCodeCamp and W3Schools work on mobile.
2. **Write real code on the phone:** Pydroid 3 for Python, Acode for HTML, CSS and JavaScript.
3. **Practise a little every day.** Short lessons on the daladala count.
4. **Use campus or cyber café computers** for bigger projects, Git and your portfolio.

Tip: download lessons on Wi-Fi so your bundle lasts longer.

## Know the limits

- **Small screen, slow typing:** fine for learning, hard for big projects.
- **Some tools need a computer:** Android Studio, Docker and most IDEs.
- **Jobs expect a laptop.** Save a little each month toward one.

Limits are not a reason to wait. Start with what you have. *Anza ulipo.*

## Your 7-day task

Install Pydroid 3 or Acode, write a program that prints your name and age, and post a screenshot. Done? Comment **"Nimefanya"** and show me.

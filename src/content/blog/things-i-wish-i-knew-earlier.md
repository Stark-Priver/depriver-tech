When I started, I thought being a good developer meant knowing the newest framework. It took me a while to learn that the people who grow fastest focus on a few simple habits.

## The five lessons

1. **Fundamentals beat frameworks.** Frameworks change every year. How the web works, data structures, Git, SQL and debugging don't. Build one project with no framework at all.
2. **Read more code than you write.** Most of the job is understanding code that already exists. Read one open-source repo a week and trace a feature from the UI to the database.
3. **Ask better questions.** Being stuck for hours isn't a badge of honour. Try first, then ask with context: what you tried, the exact error, and what you expected.
4. **Ship first, then improve.** Done and working beats perfect and unfinished. Deploy early, even to a test server, and let real users teach you.
5. **Grow beyond the code.** Communication, writing and understanding the problem are what make you valuable. Syntax is only part of the job.

Starting to code can feel overwhelming: so many languages, tutorials and opinions. This carousel is the roadmap I'd give my younger self.

## The short version

- **Choose one language based on your goal.** Websites: HTML, CSS and JavaScript. Data and AI: Python and SQL. Mobile: Dart with Flutter, or Kotlin.
- **Master five concepts.** Variables, conditions, loops, functions and data structures. Every language is built on them, so once you understand them, switching languages is easy.
- **Learn the tools of the trade.** Git and GitHub, the terminal, a good editor and how to debug.
- **Be consistent.** Thirty minutes every day beats five hours once a week. Type code yourself, read error messages from the last line up, and build small projects.

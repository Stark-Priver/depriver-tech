"Guys tumefika wapi?" We all know the group project where one person does everything, the others add their names, and the code travels around on a flash drive as `final_FINAL2.zip`. At work, everyone ships and Git shows who did what. Here's how to run your group project like a real team. *Kazi ya kikundi, si ya mtu mmoja.*

## Split the work on day one

| Role | Owns |
|---|---|
| Lead | The plan and the check-ins |
| Frontend | Screens and user flow |
| Backend | API, logic and security |
| Database | Tables and sample data |
| Docs & tests | The report, the README and testing |

Put names next to tasks in the group chat, so there's no confusion later.

## Make the work visible

Use a task board with three columns (To do, Doing, Done) and a name on every card. Free tools: GitHub Projects, Trello, or a shared Google Sheet. Nobody can hide when the board shows every task.

## No more final_FINAL2.zip

- Everyone works on **their own Git branch**.
- Merge into `main` through a **pull request**.
- **Commit messages** show who did what.

Bonus: your Git history becomes proof of your contribution.

## 15 minutes, every week

Each person answers three questions: **What did I finish? What will I do next? What's blocking me?** Ask for help early, not the night before, and write the decisions in the group chat after every meeting.

## When someone doesn't contribute

1. **Talk early, in private.** Maybe they're stuck or struggling, so ask kindly.
2. **Give a clear task and a date**, small and specific, written in the chat.
3. **Keep records:** the task board, Git history and chat decisions.
4. **Then tell the lecturer**, calmly, with the records, not gossip.
5. **Never cover silently.** Doing their part hides the problem, and you burn out.

Being fair is not being harsh. Records protect everyone.

## Presentation day

- **Each person presents their part.** You built it, so you explain it.
- **Rehearse together once.** Time it and fix the hand-overs.
- **Demo on real data**, with screenshots ready in case the network fails.
- **Know the whole project**, because questions can go to anyone.

**Who's the one doing everything in your group?** Tag your group members (kindly), and share this in your project WhatsApp group.
